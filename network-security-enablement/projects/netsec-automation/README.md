# NetSec Automation

Cloud-specific project handoffs for Network Security Enablement.

- [AWS](aws/README.md): project operational handoff, including the dependent [security-group consolidation / migration process](aws/processes/security-group-consolidation-migration/README.md).
- [GCP](gcp/README.md): separate scope to define; no AWS procedures or capabilities are assumed to apply.

Each cloud has its own handoff record. This page is navigation, not a combined acceptance decision. Accepting AWS responsibilities does not accept GCP responsibilities, or vice versa. Shared material can be linked when genuinely common without duplicating cloud-specific procedures.
