## Scope

NSE supports QE defect troubleshooting for **all AWS automation patterns**, during agreed IST hours; the overall assignment covers both AWS and GCP. The pattern sheet identifies current versus planned behavior. Follow the [project expectations](../shared/README.md) and the [AWS QE defect workflow](qe-defect-handling.md). NSE diagnoses/co-ordinates fixes and helps requestors with request forms to provision missing access and implementation that meet NetSec Standard Tech 08.11 with appropriate business justification. Shared automation/service-catalog changes, including missing CRE pattern access, go to NSAE because of their wider impact.
